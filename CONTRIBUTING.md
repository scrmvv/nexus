# Contributing

Thanks for your interest in NEXUS.

## Development

- Use Node.js 20 or later (`node -v`). There are no npm runtime dependencies.
- Copy `.env.example` to `.env` for local testing. Use **demo mode** if no Linux access log is available.
- Run `npm test` before proposing changes.
- Open a focused issue or pull request explaining the problem, expected behavior and how you tested it.
- Do not include real server hostnames, visitor IPs, logs, passwords, bot tokens or screenshots containing private activity in issues or commits.

## Security reports

Please use the [security policy](SECURITY.md) instead of posting exploitation details in public issues.
